# Jugal Mehta's React Portfolio (Practicals 1-3)

This Vite + React portfolio covers the first three AWDF practicals.

## Practical coverage

- **Practical 1:** reusable `Header`, `About`, `Skills`, and `Footer` components. `Header` receives a name/theme prop and `Skills` receives an array prop from its page.
- **Practical 2:** React Router navigation, active NavLinks, a controlled contact-message input with live character count, and a visibility toggle for message help.
- **Practical 3:** GitHub REST API integration on the Projects route, with `useEffect`, loading spinner, error state with retry, repository search, links, and star counts.

## Run locally

```bash
npm install
npm run dev
```

Use `npm run build` to create a production build.
